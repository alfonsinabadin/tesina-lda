# Análisis de comentarios en redes sociales con latent Dirichlet allocation

Repositorio de la tesis de Licenciatura en Estadística (UNR, 2025).

## Estructura
- **data/**: bases de datos (no se versionan).
- **scripts/**: código R numerado por etapas.
- **notebooks/**: exploraciones y reportes.
- **output/**: resultados (modelos, figuras, tablas).
- **utils/**: funciones auxiliares.
- **docs/**: documentación y material de referencia.

## Reproducibilidad
1. Instalar dependencias: `install.packages(readLines("requirements.txt"))`
2. Ejecutar `scripts/02_limpieza.R` → `scripts/04_lda_modelado.R`
3. Resultados en `output/figuras/` y `output/tablas/`.
